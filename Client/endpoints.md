# Account Module Endpoints Documentation (E-Commerce)

| Endpoint                 | Method | Request Body                                                                                                                                                                                  | Response                                                                                                                                                                                      | Description                                                                                    |
|--------------------------|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------|
| /account/create          | POST   | ```json<br>{<br>  "username": "string",<br>  "email": "string",<br>  "password": "string"<br>}<br>```                                                                                         | **Success:** 200 OK <br>```json<br>{ "id": "guid" }<br>``` <br> **Error:** 400 Bad Request <br>```json<br>{ "message": "An account with email 'example@example.com' already exists." }<br>``` | Creates a new user account for the e-commerce site. Passwords are hashed. Returns the user ID. |
| /account/login           | POST   | ```json<br>{<br>  "email": "string",<br>  "password": "string"<br>}<br>```                                                                                                                    | **Success:** 200 OK <br>```json<br>{ "token": "jwt-token", "userId": "guid" }<br>``` <br> **Error:** 401 Unauthorized <br>```json<br>{ "message": "Invalid email or password." }<br>```       | Authenticates a user and returns a JWT token for session management.                           |
| /account/update-profile  | PUT    | ```json<br>{<br>  "userId": "guid",<br>  "username": "string",<br>  "email": "string",<br>  "phone": "string"<br>}<br>```                                                                     | **Success:** 200 OK <br>```json<br>{ "message": "Profile updated successfully." }<br>``` <br> **Error:** 404 Not Found <br>```json<br>{ "message": "User not found." }<br>```                 | Updates the user’s profile information such as username, email, and phone.                     |
| /account/change-password | PUT    | ```json<br>{<br>  "userId": "guid",<br>  "oldPassword": "string",<br>  "newPassword": "string"<br>}<br>```                                                                                    | **Success:** 200 OK <br>```json<br>{ "message": "Password changed successfully." }<br>``` <br> **Error:** 400 Bad Request <br>```json<br>{ "message": "Old password is incorrect." }<br>```   | Changes the user’s password after verifying the old password.                                  |
| /account/add-address     | POST   | ```json<br>{<br>  "userId": "guid",<br>  "addressLine1": "string",<br>  "addressLine2": "string",<br>  "city": "string",<br>  "postalCode": "string",<br>  "country": "string"<br>}<br>```    | **Success:** 200 OK <br>```json<br>{ "addressId": "guid" }<br>``` <br> **Error:** 404 Not Found <br>```json<br>{ "message": "User not found." }<br>```                                        | Adds a new shipping/billing address for the user.                                              |
| /account/update-address  | PUT    | ```json<br>{<br>  "addressId": "guid",<br>  "addressLine1": "string",<br>  "addressLine2": "string",<br>  "city": "string",<br>  "postalCode": "string",<br>  "country": "string"<br>}<br>``` | **Success:** 200 OK <br>```json<br>{ "message": "Address updated successfully." }<br>``` <br> **Error:** 404 Not Found <br>```json<br>{ "message": "Address not found." }<br>```              | Updates an existing address for the user.                                                      |
| /account/delete          | DELETE | ```json<br>{<br>  "userId": "guid"<br>}<br>```                                                                                                                                                | **Success:** 200 OK <br>```json<br>{ "message": "Account deleted successfully." }<br>``` <br> **Error:** 404 Not Found <br>```json<br>{ "message": "User not found." }<br>```                 | Deletes the user account and all associated data.                                              |
